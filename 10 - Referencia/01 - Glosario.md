# Glosario

| Término                      | Definición                                                                                         |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| **Almanaque XII**            | El protagonista: un autómata, el duodécimo de su linaje (ver [[03 - Personajes]])                  |
| **Efeméride**                | La voz del Reloj; acompaña a los Almanaques y les da órdenes (ver [[03 - Personajes]])             |
| **Gran Reloj Cósmico**       | La máquina que fijó el destino de todos y por la que asciende el Almanaque                         |
| **Entrañas del Reloj**       | Zona del tutorial (18 salas), en la base del Reloj                                                 |
| **Pozo Celeste**             | Última sala del tutorial: el elevador al aire libre hacia el cielo                                 |
| **Eje Central**              | Zona a la que llega el elevador; cierra la demo                                                    |
| **Casas**                    | Las doce regiones zodiacales del Reloj; se ven al fondo desde el Eje Central                       |
| **Gancho de luz**            | Gancho que el jugador dispara para engancharse, balancearse o arrastrarse; tiene 2 usos            |
| **Estrella ancla**           | Punto que el jugador escribe en el vacío (tecla E) y al que puede enganchar el gancho              |
| **Cuerda (de escalada)**     | Resistencia para agarrarse a superficies rugosas: 100 puntos, se rellena al pisar suelo            |
| **Farol**                    | Punto de enganche fijo para el gancho                                                              |
| **Cristal de recarga**       | Pieza que devuelve los usos del gancho y de la estrella ancla                                      |
| **Checkpoint**               | Punto donde reaparece el jugador tras morir                                                        |
| **Sala**                     | Unidad del nivel: tiene su cámara y sus puntos de reaparición                                      |
| **Gas nebuloso**             | Peligro estático que mata al tocarlo y corta el gancho                                             |
| **Metal estelar**            | Superficie enganchable que responde al gancho con una onda de luz                                  |
| **SLSO8**                    | Paleta base de 8 colores del proyecto                                                              |
| **Tile / Rule Tile**         | Cuadro de 32 × 32 px; el Rule Tile elige solo su sprite según los vecinos, para evitar costuras    |
| **PlayerTuning**             | Asset con los números del jugador (correr, salto, pared, escalada)                                 |
| **EditMode / PlayMode**      | Dos tipos de prueba automática de Unity: sin ejecutar el juego y ejecutándolo                      |
| **CI**                       | Integración continua: GitHub ejecuta pruebas y compilaciones en cada PR                            |
