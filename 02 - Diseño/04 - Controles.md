# Controles

## Descripción de la sección

Define la relación entre las acciones del jugador y las entradas físicas del dispositivo.

## Mapa de controles

El juego es para PC, por lo que no se contempla entrada táctil.

| Acción                                  | Teclado         | Mouse                | Mando                     |
| --------------------------------------- | --------------- | -------------------- | ------------------------- |
| Mover                                   | W A S D         |                      | Stick izquierdo o cruceta |
| Saltar                                  | Espacio         |                      | A                         |
| Agarrarse y escalar (mantener)          | Shift izquierdo |                      | LT                        |
| Apuntar                                 |                 | Posición del puntero | Stick derecho             |
| Gancho: balanceo                        |                 | Clic izquierdo       | RT (mantener)             |
| Gancho: arrastre                        |                 | Clic derecho         | RB                        |
| Anclaje de apoyo                        | E               |                      | LB                        |
| Interactuar (observar, leer, descansar) | W               |                      | Y                         |
| Menú / pausa                            | TAB             |                      | Start (por confirmar)     |

## Principios de control

- Los controles deben ser consistentes.
- Las acciones críticas deben ser fáciles de identificar.
- Debe existir retroalimentación visual, sonora o háptica cuando corresponda.
- Evitar combinaciones innecesariamente complejas.
- Un botón por modo del gancho: pulsar de nuevo el botón del modo en uso corta el gancho.
- El anclaje se puede colocar en cualquier estado (suelo, aire o pared).
- El salto y el gancho perdonan la entrada (coyote time y buffer de pulsación) para que el castigo sea justo.

## Reasignación

¿El jugador puede cambiar los controles?

No

## Entrada y retroalimentación

Describe qué ocurre inmediatamente después de cada entrada importante. Las señales usan los anillos del Astrolabio en el HUD y efectos de chispas, polvo y destellos.

| Entrada  | Señal para el jugador                                                                    |
| -------- | ---------------------------------------------------------------------------------------- |
| Saltar   | Chispa breve y sonido de salto al despegarse del piso.                                   |
| Anclaje  | Mira azul si la posición es válida y roja si no, destello al colocarse.                  |
| Gancho   | Los anillos del Astrolabio se encienden para mostrar los usos y se apagan al gastar uno. |
| Escalar  | La llave gira; tiembla y suena un clic acelerado al estar por agotarse la cuerda.        |
| Balanceo | La cuerda se pone roja en los últimos segundos.                                          |
