# Público y plataforma

Astrolabio es un plataformas 2D de precisión para PC y un solo jugador. Está dirigido a personas de 16 años en adelante que ya conocen el género y disfrutan una dificultad exigente pero justa: dominar el movimiento, superar cada sala y reintentar de inmediato. Les atraen el pixel art, las atmósferas oscuras y una narrativa que se descubre mirando.

La dificultad se apoya en reglas legibles: cuántos usos del gancho quedan, qué superficie se agarra y qué mata se distingue sin texto. La demo dura entre 15 y 25 minutos según la habilidad del jugador; es una estimación que aún no se ha medido con jugadores nuevos (ver [[02 - Pruebas]]).

| Elemento             | Decisión                                                                              |
| -------------------- | ------------------------------------------------------------------------------------- |
| Plataforma           | PC (Windows); consola, por evaluar a futuro                                           |
| Distribución         | Demo gratuita en itch.io, con donaciones voluntarias (ver [[01 - Alcance]])           |
| Entrada              | Teclado y ratón; mando, apuntando con el stick derecho (ver [[04 - Controles]])       |
| Resolución           | 1920 × 1080; vista base de 1280 × 720 (40 × 22,5 tiles de 32 px), escala ×1,5 a 1080p |
| Relación de aspecto  | 16:9                                                                                  |
| Rendimiento objetivo | 60 FPS estables                                                                       |
| Conexión             | No requerida                                                                          |
| Guardado             | La demo no guarda el progreso (ver [[04 - Guardado y Configuración]])                 |
