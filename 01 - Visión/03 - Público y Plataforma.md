# Público y Plataforma

## Descripción de la sección

Define para quién se diseña el videojuego y dónde se jugará. Las decisiones de diseño, interfaz, controles y rendimiento dependen de estas variables.

## Público objetivo

**Edad aproximada:** 16 años en adelante

**Experiencia esperada:**  
Controles intuitivos y fáciles de aprender, con un desafío exigente pero justo; la emoción de dominar el movimiento y la satisfacción de superar cada sala.

**Intereses relevantes:**
Plataformas 2D de precisión, pixel art y atmósferas oscuras, narrativa ambiental y mecánicas de movimiento.

**Conocimientos previos necesarios:**
Familiaridad con el género de plataformas.

## Plataforma

| Elemento                | Decisión                                              |
| ----------------------- | ----------------------------------------------------- |
| Plataforma principal    | PC (Windows)                                          |
| Plataformas secundarias | Consola (por evaluar a futuro)                        |
| Distribución            | itch.io                                               |
| Método de entrada       | Teclado y mouse; mando (se apunta con el stick derecho)                    |
| Resolución objetivo     | 1920x1080 (base de pixel art de 640x360, escala entera ×3) |
| Relación de aspecto     | 16:9                                                  |
| Rendimiento objetivo    | 60 FPS estables                                       |
| Conexión requerida      | No                                                    |

## Restricciones de plataforma

Documenta limitaciones de hardware, controles, memoria, almacenamiento, distribución o conectividad.

- Distribución: la build de Windows se publicará en itch.io.
- Controles: el anclaje y el gancho dependen de apuntar; con mando se apunta con el stick derecho y se diseñan ayudas de puntería para compensar la menor precisión del stick (ver [[04 - Controles]]).
- Almacenamiento: el progreso se guarda al descansar en un observatorio mayor y al tomar el ascensor entre Casas (ver [[04 - Guardado y Configuración]]).

## Sesión de juego

**Duración esperada de una sesión:** 10 minutos

**Duración total estimada del juego:** Entre 45 y 90 minutos (demo con tres niveles; depende de la habilidad del jugador)

## Modelo de distribución

> Gratuito, pago único, educativo, prototipo académico, etc.

Demo gratuita en itch.io, con donaciones voluntarias para apoyar el desarrollo de una versión completa.
